# Hedonism — лонгрид

Провокативный лонгрид о том, что естественные желания давно удовлетворены, а остальные нам навязывают извне. Опирается на Эпикура, Бодрийяра («Общество потребления»), Жирара, Канемана.

## Вёрстка

Макет: Figma «Hedonizm», секция «2»; блоки 06, 08, 09, 11, 12 — по обновлённой «Section 1» (node 286:352) (артборды шириной 1440, высота у каждого блока своя — `--h`).

- **Десктоп (≥ 900px)** — блоки 01–12 собраны на артборде шириной 1440: `1u` = 1px макета, масштабируется под ширину вьюпорта (container query units) и ограничен 1440px.
- **Мобильный (< 900px)** — артборд превращается в поток: коллаж из фото в две колонки, заголовок наезжает на фото, шкала потребностей Эпикура складывается в столбик; композиция с пирогом (03) сохраняется, но пересобрана на сетке 375; чеки (05) уходят над и под список.

## Анимация

В блоке 03 куски пирога в розовых квадратах разного размера появляются по одному в случайных местах, счётчик растёт с 1 до 10, сразу после этого квадраты по одному исчезают обратно до 1 — и так по кругу; каждый круг квадраты встают в новые места и меняют размер (`js/slice.js`). Анимация идёт, только пока блок на экране. При `prefers-reduced-motion` сразу показываются все 10.

В блоке 05 при первом появлении на экране три чека по очереди вылетают справа из-за края экрана, затем строки списка сверху вниз: слово зачёркивается линией, сереет, и выезжает альтернатива («→ образ жизни»); в конце появляется цитата (`js/signs.js`, стили — в `style.css`). Без JS и при `prefers-reduced-motion` блок сразу в финальном виде.

## Стек
