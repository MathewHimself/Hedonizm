# Hedonism — лонгрид

Провокативный лонгрид о том, что естественные желания давно удовлетворены, а остальные нам навязывают извне. Опирается на Эпикура, Бодрийяра («Общество потребления»), Жирара, Канемана.

## Вёрстка

Макет: Figma «Hedonizm», секция «2» (артборды шириной 1440, высота у каждого блока своя — `--h`).

- **Десктоп (≥ 900px)** — блоки 01–08 собраны на артборде шириной 1440: `1u` = 1px макета, масштабируется под ширину вьюпорта (container query units) и ограничен 1440px.
- **Мобильный (< 900px)** — артборд превращается в поток: коллаж из фото в две колонки, заголовок наезжает на фото, шкала потребностей Эпикура складывается в столбик; композиция с пирогом (03) сохраняется, но пересобрана на сетке 375; чеки (05) уходят над и под список.

## Стек

Чистые HTML/CSS, без сборки. Шрифты — Google Fonts: Open Sans (Condensed ExtraBold через ось `wdth` 75), Inter, JetBrains Mono.

## Запуск

Открыть `index.html` в браузере или:

```bash
npx serve .
```
