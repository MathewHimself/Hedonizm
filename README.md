# Hedonism — лонгрид

Провокативный лонгрид о том, что естественные желания давно удовлетворены, а остальные нам навязывают извне. Опирается на Эпикура, Бодрийяра («Общество потребления»), Жирара, Канемана.

## Вёрстка

Макет: Figma «Hedonizm», секция «2» (артборды 1440 × 900).

- **Десктоп (≥ 900px)** — блоки 01–02 собраны на артборде 1440 × 900: `1u` = 1px макета, масштабируется под ширину вьюпорта (container query units) и ограничен 1440px.
- **Мобильный (< 900px)** — артборд превращается в поток: коллаж из фото в две колонки, заголовок наезжает на фото, шкала потребностей Эпикура складывается в столбик.

## Стек

Чистые HTML/CSS, без сборки. Шрифты — Google Fonts: Open Sans (Condensed ExtraBold через ось `wdth` 75), Inter, JetBrains Mono.

## Запуск

Открыть `index.html` в браузере или:

```bash
npx serve .
```
