# Hedonism — лонгрид

Провокативный лонгрид о том, что естественные желания давно удовлетворены, а остальные нам навязывают извне. Опирается на Эпикура, Бодрийяра («Общество потребления»), Жирара, Канемана.

## Hero

Метафора: бесконечный шведский стол уходит за край экрана, а тарелка у человека одна.
Тарелки раскладываются от краёв к центру и медленно дрейфуют влево. При `prefers-reduced-motion` анимация отключена.

## Стек

Чистые HTML/CSS/JS, без сборки. Шрифты — Google Fonts: UnifrakturMaguntia, Cormorant Garamond, Onest, JetBrains Mono.

## Запуск

Открыть `index.html` в браузере или:

```bash
npx serve .
```

## Деплой на GitHub Pages
